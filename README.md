# FNP Sales Analysis Dashboard – Excel

## Project Overview
The FNP Sales Analysis Dashboard is an interactive Excel dashboard designed to analyze sales performance and identify important business insights. The dashboard provides a comprehensive overview of orders, revenue, customer spending, product performance, and delivery time.

It helps understand sales trends across different occasions, product categories, months, and cities, enabling better business decision-making.

## Tools & Technologies Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas
- Data Visualization

## Key Performance Indicators (KPIs)
- **Total Orders:** 1,000
- **Total Revenue:** ₹35,20,984
- **Average Order-Delivery Time:** 5.53 days
- **Average Customer Spending:** ₹3,520.98

## Dashboard Features

1. **Revenue by Occasion:** Analyzes revenue generated across different occasions such as Valentine's Day, Diwali, Birthdays, Anniversaries, and Raksha Bandhan.

2. **Revenue by Category:** Displays revenue distribution across product categories, including Cakes, Colors, Mugs, Plants, Raksha Bandhan, Soft Toys, and Sweets.

3. **Revenue by Hour:** Identifies hourly sales patterns based on order time.

4. **Monthly Revenue Analysis:** Tracks revenue trends across all 12 months.

5. **Top 5 Products by Revenue:** Highlights the five highest-revenue-generating products.

6. **Top 10 Cities by Orders:** Identifies cities contributing the highest number of orders.

## Interactive Features
- Order Date slicer for filtering sales by date.
- Delivery Date slicer for analyzing delivery periods.
- Occasion slicer for viewing occasion-specific performance.
- Dynamic charts and visualizations for interactive analysis.

## Key Insights
- Colors generated the highest revenue among the displayed product categories.
- August and February recorded strong monthly revenue performance.
- Magnam Set was the highest-revenue-generating product among the top five displayed products.
- Imphal and Dhanbad recorded the highest order volumes among the displayed cities.
- The average order-delivery time was 5.53 days.

## Project Objective
The main objective of this project is to transform raw sales data into meaningful visual insights using Microsoft Excel. It demonstrates practical skills in data analysis, data visualization, Pivot Tables, and interactive dashboard development.
